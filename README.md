# rx-vial-3d

Scroll-driven 3D product page for **Aurel**, a fictional telehealth brand. Built with Next.js, React Three Fiber and GSAP, with "View in AR" on phones.

Live: https://klivak.github.io/rx-vial-3d/

Status: phase 1 (scaffold and deploy) of [docs/PLAN.md](docs/PLAN.md). Specification: [docs/SPEC.md](docs/SPEC.md).

## Run locally

```bash
pnpm install
pnpm dev                      # http://localhost:3000
pnpm dev --hostname 0.0.0.0   # open from a phone on the same network
pnpm build                    # static export to out/
```
